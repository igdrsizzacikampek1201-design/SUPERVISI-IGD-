Integrasi Google Sheets Webhook

Hubungkan aplikasi dengan Spreadsheet Anda melalui Apps Script URL

Data rekap supervisi dan hasil input perawat akan dikirim otomatis ke spreadsheet Anda saat tombol simpan ditekan.

Cara Singkat Setup Google Sheets:

1. Buat Google Spreadsheet baru.
2. Buka Extensions > Apps Script dan paste script penerima JSON.
3. Deploy sebagai Web App (Access: Anyone), lalu salin URL Web App dan paste di atas.
